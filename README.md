## 课程修读与避坑指南（学长实战经验）

### 1. 课程先修关系与三门 PLC 实践联动
- 本课程通常在**大三上学期第 1-2 周**开展，是自动化专业三门 PLC / 工控实践课程中最先修的一门；
- 本课程与后续紧接着开展的两门高阶实践课程高度衔接，三门课均在 PLC 实验室开展，可结合修读：
  1. [自动控制系统综合实践（WG327420）](../自动控制系统综合实践/)（大三上第 3-4 周开展，涵盖温控、步进、变频器与通信）；
  2. [工业自动化先进技术综合实践（WG327430）](../工业自动化先进技术综合实践/)（解包工业工程与先进控制）。

### 2. 开发工具与环境推荐
- **强烈推荐自带电脑**：
  - 实验室自带电脑配置较老，运行卡顿；
  - 建议携带笔记本电脑现场插网线直连 PLC；
  - 推荐安装西门子博途（TIA Portal V15.1）并启用 **TIA Openness**；
  - 借助 Openness 接口与现代 AI 工具（如 Codex / AI 编程助手）可实现控制逻辑与符号表的自动化生成，大幅提升编程效率。

### 3. 实践内容与授课节奏
- **主要内容**：建立对西门子 PLC 硬件架构、I/O 寻址、通信配置及编程环境的系统认识，重点完成**十字路口交通灯控制系统**的逻辑设计与台位联调；
- **授课节奏**：前期老师会统一讲解 PLC 基础原理、控制要求与实验规范；之后根据要求自主完成程序编写、下载与现场实验台动作验证。

### 4. 考勤签到
- 采用 **学习通线上签到 + 课堂纸质版签到** 双重考勤模式，务必按时打卡签到。
